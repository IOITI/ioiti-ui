# Logos

`favicon.svg` is the mark of an application made with the system: a monogram "I" in a 32 × 32 square with 8px corners, `#0a0a0a` ground and `#fafafa` letter (the light theme's `text-primary` and `background`). It is the tab's icon of the gallery and of the starter template. Its colours are fixed: on a dark page it keeps its ink square.

In the interface the mark is drawn, not loaded: `AppBrand` sets the application's first letter (or the `mark` it is given) in a `radius-lg` square of `foreground` with `background` letters, the accent's `brand` fill (Bloom: its gradient) where one is chosen. IOITI has no wordmark in the sources: set the application's name in Geist, `section-title`, beside the mark.
